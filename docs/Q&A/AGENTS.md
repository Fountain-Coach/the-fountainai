# Q&A Agent

## Purpose
This directory collects question-and-answer articles that form a human-readable, interlinked wiki for FountainAI.

## Conventions
- One question per Markdown file.
- Name each file using the full question in **kebab-case**, ending with `.md`.
- Start the file with the question as an `#` heading followed by the answer.
- Link to related questions using relative paths when helpful.
- Keep explanations concise and readable.

## Programmatic Checks
- Run `swift build` and `swift test` from the repository root; no additional checks are required for docs.
